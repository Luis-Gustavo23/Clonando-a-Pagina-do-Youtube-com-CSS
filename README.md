# 🎬 Clonando a Página do YouTube com CSS

Projeto desenvolvido com o objetivo de praticar **HTML5** e **CSS3**, recriando a interface da página de exibição de vídeo do YouTube.

---

## 🚀 Acesse o Projeto Online

🔗 **Visualizar no GitHub Pages:**  
https://luis-gustavo23.github.io/Clonando-a-Pagina-do-Youtube-com-CSS/

---

## 📌 Sobre o Projeto

Este projeto consiste na clonagem estática da página principal de vídeo do YouTube (versão desktop), focando exclusivamente em:

- Estruturação semântica com HTML5
- Layout com Flexbox
- Organização e boas práticas em CSS
- Posicionamento e alinhamento de elementos
- Estilização de botões e imagens
- Separação entre conteúdo e estilo

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox

---

## 🎯 Funcionalidades Desenvolvidas

- Header com:
  - Botão de menu
  - Logo
  - Barra de busca
  - Ícones de ações
  - Avatar do usuário (como botão)

- Conteúdo principal:
  - Player de vídeo (iframe)
  - Título do vídeo
  - Informações do canal
  - Botão de inscrição
  - Botões de ação (like, compartilhar, download)

- Barra lateral:
  - Lista de vídeos recomendados
  - Thumbnail
  - Informações do vídeo

---

## 📐 Conceitos Aplicados

- Reset CSS com `box-sizing: border-box`
- Uso consistente de `display: flex`
- Organização por blocos semânticos (`header`, `main`, `article`, `aside`)
- Uso correto de botões para elementos interativos
- Aplicação de `object-fit` para imagens
- Separação de responsabilidades (HTML estrutura / CSS estilo)

---

## 🚀 Objetivo do Projeto

Este projeto foi criado como exercício prático para:

- Melhorar habilidades em layout com Flexbox
- Praticar organização de código CSS
- Simular um layout real de aplicação web
- Evoluir para projetos mais complexos futuramente
